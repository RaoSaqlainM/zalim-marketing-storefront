# Zalim-Marketing Reference-Inspired Page Audit

The public reference storefront establishes a useful **functional** hierarchy: a utility announcement bar, vehicle make/model/year selector, popular-category grid, high-selling product section, category shortcuts, search/account/basket utilities, customer-support entry points, mailing-list capture, and a WhatsApp handoff. Zalim-Marketing will use an original visual system, original catalog text and assets, and a different brand identity while matching this broad marketplace coverage.

| Reference-inspired capability | Original Zalim-Marketing implementation |
|---|---|
| Vehicle selector | A clearly reachable vehicle finder with UK, US, and Australian make/model/year context and product-fit guidance. |
| Popular categories | Original categories for car care, lighting, cabin, utility, mobile essentials, touring, and upgrades. |
| Product merchandising | EUR-denominated product cards, filters, category/brand routes, search, and original fit notes. |
| Account and basket utilities | Linked account and basket pages plus a non-payment order-enquiry path. |
| Customer support | Owner-approved WhatsApp and email locations, without the reference site’s phone, email, links, or reviews. |
| Supporting content | Original about, FAQ, delivery, returns, contact, privacy, and terms pages. |

The user expressly requested a professional, complete marketplace. The corrective rebuild will prioritize readable desktop layouts, fully reachable navigation, direct page links, smaller predictable interactions, and mobile-safe content hierarchy. It will not reproduce the source site’s branding, product imagery, copy, customer reviews, code, or linked resources.
