# Desktop Hero Composition Audit

**Viewport review:** 1,280 × 800 and 1,920 × 1,080.

The current desktop hero is visually busy but still reads as a set of floating blocks because the drive-profile card is vertically centred in a broad right column while the foreground vehicle remains mostly hidden underneath it. At wide widths, this leaves unassigned dark background above, below, and to the outside of the card; at laptop widths, it compresses the right-side car into a narrow sliver.

The repair is structural rather than another size adjustment. The desktop hero should use deliberate full-height zones: a concise left editorial rail, a right-side vehicle-finder terminal that owns its column from top to bottom, and a clearly visible vehicle showcase area within that terminal. This prevents the hero from depending on empty background to separate floating elements.

## Completed repair

The floating vehicle-finder card has been replaced with a full-height desktop terminal. It now contains the market choices, a vehicle-led browsing module with independent foreground artwork, and a fitment-route action at the base. Wide desktop validation confirms that the previously unused panel area is now occupied by intentionally grouped content; mobile retains the original compact hero because the terminal is desktop-only.
